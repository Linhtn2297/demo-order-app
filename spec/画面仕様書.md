# 受注管理システム 画面仕様書

版数: 1.2（2026-08-20）

## 1. ログイン画面

### 1.1 概要

ID とパスワードで認証し、成功時は注文一覧画面へ遷移する。

### 1.2 入力項目

| 項目 | 必須 | 備考 |
|---|---|---|
| ID | ○ | 半角英数字 |
| パスワード | ○ | 入力内容は伏せ字で表示する |

### 1.3 メッセージ

| 条件 | 表示メッセージ | 表示位置 |
|---|---|---|
| ID またはパスワードが未入力 | IDとパスワードを入力してください | フォーム上部 |
| 認証失敗（ID・パスワードの不一致） | IDまたはパスワードが正しくありません | フォーム上部 |

- 認証失敗時は入力フォームを再表示し、ID の入力内容は保持する。
- セキュリティのため、ID とパスワードのどちらが誤っているかは区別しない。

## 2. 注文一覧画面

### 2.1 概要

注文を検索し、一覧表示する。全ロールが利用できる（権限は「権限一覧.xlsx」を参照）。

### 2.2 検索条件

| 項目 | 検索方法 | 備考 |
|---|---|---|
| 顧客名 | 部分一致 | 前後の空白は除去して検索する |
| 注文日 | 範囲指定（From〜To） | どちらか一方のみの指定も可 |
| ステータス | 完全一致 | 下書き / 確定 / 出荷済 / すべて |

- 条件を指定しない場合は全件を対象とする。
- 検索結果は注文日の降順で表示し、最大 100 件までとする。

### 2.3 一覧項目

| 項目 | 表示形式 |
|---|---|
| 注文番号 | ORD-0000 形式 |
| 注文日 | YYYY-MM-DD |
| 顧客名 | — |
| 合計金額 | ¥ 付き、3桁区切り |
| ステータス | 下書き / 確定 / 出荷済 |
| 操作 | 編集・削除ボタン（権限があるユーザーのみ表示） |

### 2.4 ボタン

| ボタン | 動作 | 表示条件 |
|---|---|---|
| 検索 | 検索条件で一覧を更新する | 常に表示 |
| 新規作成 | 注文編集画面を開く | 注文の保存権限があるユーザー |
| 編集 | 注文編集画面を開く | 注文の保存権限があり、出荷済でない注文 |
| 削除 | 確認ダイアログの後に削除する | 注文の削除権限があるユーザー |

## 3. 注文編集画面

### 3.1 入力項目

| 項目 | 必須 | 入力チェック |
|---|---|---|
| 注文日 | ○ | 日付形式 |
| 顧客名 | ○ | — |
| 合計金額 | ○ | 0 以上の整数 |
| ステータス | ○ | 下書き / 確定 / 出荷済 |

### 3.2 業務ルール

- 新規作成した注文のステータスは「下書き」とする。
- 出荷済の注文は変更できない。
- 保存・削除できるロールは「権限一覧.xlsx」に従う。
